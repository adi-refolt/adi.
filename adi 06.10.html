Веб-жобаның синхрондалуы

Git және GitHub арқылы Local және Remote жобаларды синхрондау

Жоба туралы

Бұл веб-жоба GitHub-пен жұмыс істеуді, Local Repository және Remote Repository арасындағы байланысты үйренуге арналған.

Local → Remote: git add → git commit → git push

Remote → Local: git fetch / git pull

Git негізгі командалары

git status
git add .
git commit -m "Өзгеріс енгізілді"
git push
git pull
git fetch

Синхрондау тәртібі

1. git pull
2. Файлдарды өзгерту
3. git status
4. git add .
5. git commit -m "Сайт жаңартылды"
6. git push

Merge Conflict

Егер екі адам бір файлдың бір бөлігін әртүрлі өзгертсе, Merge Conflict пайда болуы мүмкін.

Мұндай жағдайда конфликтті қолмен шешіп, кейін қайтадан add, commit және push командаларын орындау қажет.
